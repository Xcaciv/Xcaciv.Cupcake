## 2. [MINOR] §7.11 AC-11.22

**Problem:** The criterion quotes the expected restore-failure message as `The local source '/mnt/g/reversing/reversing/subject/Xcaciv.Cupcake/%NUGET_LOCAL_PACKAGES%' doesn't exist.` — an absolute path from the reverse-engineering workspace, not from the product. No clone team can ever observe that string, so the criterion is unrunnable as written and it leaks the analysis host's filesystem layout into a delivered document. §7.2's Source notes get this right, quoting `<repo-root>/%NUGET_LOCAL_PACKAGES%`, and §7.2 AC-2.29 gets it right by asserting only that the path "literally contains `%NUGET_LOCAL_PACKAGES%`".

**Required fix:** Replace the quoted literal with `The local source '<repo-root>/%NUGET_LOCAL_PACKAGES%' doesn't exist.` and add the same wording used in AC-2.29 — the assertion is that the environment token survives unexpanded and is resolved relative to the directory holding the feed manifest, not that any particular absolute path appears. Sweep §7.11 for other occurrences of the `/mnt/g/reversing/...` prefix (it also appears in UC-11.C E1).

## 3. [MINOR] §7.1 US-1.13, US-1.14; §7.2 US-2.9; §7.3 US-3.8, US-3.12; §7.6 US-6.5; §7.9 US-9.5, US-9.6; §7.10 US-10.15; §7.11 US-11.9, US-11.10

Where no benefit can be evidenced from the source, say so explicitly rather than omitting the clause.
