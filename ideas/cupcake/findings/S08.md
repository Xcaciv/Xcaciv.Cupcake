## 1. [CRITICAL] §7.2 FR-2.37 and AC-2.15 (also §7.2 UC-2.3 E3, §7.10 FR-10.4, §8 DM-3 Lifecycle, §11.2 Q-10) — contradicted by §7.8 FR-8.16

**Problem:** Five locations assert the disproved consequence as fact, and one of them is an executable acceptance criterion a clone would be tested against. §7.2 FR-2.37: "an entry `PACKAGESOURCEURL` with an empty value appears in every subsequent Session Variable dump"; §7.2 AC-2.15: "**and** a Session Variable dump afterwards shows an entry `PACKAGESOURCEURL` with an empty value"; §7.10 FR-10.4: "shall store an empty value under it as a side effect, after which a Session Variable dump lists it"; §8 DM-3: "the first Package Search **permanently** adds an empty `PACKAGESOURCEURL` entry that a subsequent variable dump then lists" — which the same paragraph then contradicts three sentences later with its own write-back rule; §11.2 Q-10 records it as a quirk of "the variable store" and attributes it to "6, 7.2" only. §7.8 FR-8.16 is correct: the child scope is discarded because Package Search is registered as not modifying Session Variables. A clone built to AC-2.15 must either wire write-back for a non-modifying Command or ship a test its faithful implementation fails.

**Required fix:** Correct all five. FR-2.37 and §7.10 FR-10.4: end at "...writes the default back into the Command's per-execution child scope, which is then discarded because Package Search is not registered as environment-modifying; the Session's store is unchanged." AC-2.15: replace the second clause with "**and** a Session Variable dump afterwards shows **no** `PACKAGESOURCEURL` entry — the write landed in the discarded child scope; the write is observable only when a host invokes the Command directly against its own store." §8 DM-3: delete "permanently" and the dump clause, and cross-reference the write-back sentence in the same paragraph. §11.2 Q-10: restate as "a read mutates the Command's child scope (invisible in the Session today, and visible the moment a Command is declared environment-modifying)" and add §7.8 to its § column.
